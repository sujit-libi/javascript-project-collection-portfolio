    How this works

    Browsing

    • Click a folder in the tree to run that project in the preview pane.
    • Click a file to open its source in a code pane beside the running preview.
    • Open as many files as you like. Each becomes a tab in the code pane.

    Panes

    • Drag the divider between the panes to resize either one.
    • Switch between side by side and stacked with the split button.
    • Maximise the code pane when you want to read properly, then restore it.
    • Below 900px wide the panes always stack, since two narrow columns are unreadable.

    Keyboard

    /Focus the filter
    ?Open this panel
    Ctrl BShow or hide the file tree
    Ctrl \Switch split direction
    EscClose the code pane, or clear the filter
    ← →Resize a divider once it has focus

    Adding a project

    1. Create a new folder with its own index.html.
    2. Run node generate-projects.js to rebuild the manifest.
    3. Refresh this page.

    The browser cannot list folders on its own, which is why the manifest exists. Serve the folder over http with npx serve . rather than opening the file directly.
